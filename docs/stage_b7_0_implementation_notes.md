# B.7-0 状态模型与影响预览实施记录

> 完成日期：2026-07-17

## 已完成内容

### 生命周期数据底座

新增以下幂等表结构：

- `person_affiliation`：学生/职工当前及历史校内关系。
- `identity_lifecycle_event`：未来休学、毕业、调岗、离职、停用和销户的统一事件。
- `account_closure_request`：主动销户、冷静期、撤回和完成状态。
- `responsibility_handover`：课程、审核任务、辅导个案等责任移交。
- `account_status_history`：账号状态变化与会话版本历史。

真实演示库基线：

```text
verified_identities = 23
affiliations = 23
self_service_bindings = 23
status_history = 23
```

### 隐藏基础自助身份

- 每个已核验自然人获得 `self_service` 角色绑定和 `person_identity` 本人范围。
- 该绑定不可在存在正常业务角色时选择，因此原有登录与多角色切换行为不变。
- 当业务角色全部暂停时，认证自动使用 `self_service`。
- `self_service` 没有教学数据表权限，只包含个人中心能力。
- 新注册账号审核通过时立即建立人员关系和基础绑定，不需要等待系统重启。

### 只读生命周期详情

新增接口：

```text
GET /api/lifecycle/me
GET /api/lifecycle/me/impact?event_type=...
GET /api/lifecycle/people/{person_identity_id}
GET /api/lifecycle/people/{person_identity_id}/impact?event_type=...
```

详情包含账号、人员身份、学籍/任职关系、角色与范围、岗位、历史生命周期事件和账号状态历史。

访问范围：

- 本人只能查看本人。
- 辅导员只能查看其角色绑定覆盖行政班中的学生。
- 学院负责人和身份审核员只能查看本学院人员。
- 教务人员查看学生生命周期。
- 管理员查看平台范围内人员。
- 教师和学生不能查看其他人员。

### 统一影响计算器

支持预览：

- 岗位结束、职工调岗、离职和退休。
- 学生休学、复学、毕业和退学。
- 账号安全停用和主动销户。

报告内容包括：

- 将受影响的角色绑定。
- 有效岗位和最低覆盖阻塞。
- 会话版本及是否需要撤销全部会话。
- 已领取审核任务。
- 教学班、未完成作业、辅导员未关闭个案等责任。
- 必须交接项、阻塞项、警告和是否具备执行前提。

影响预览不写业务数据，并固定返回：

```json
{
  "read_only": true,
  "execution_available": false
}
```
