# 阶段 E：教务与学院工作台实施说明

完成日期：2026-07-17

质量基线：全量自动化测试 `122 passed`。

## 已交付能力

- 教师、学院、教务按各自范围读取教学任务台账和成绩提交列表；两类列表均支持折叠、内部滚动、关键词搜索，以及按范围动态生成的学年/学院下拉项与学期、成绩状态组合筛选。
- 教务刷新未排教室、超容量和低选课确定性异常；教务和所属学院处理异常，解决时必须填写说明。
- 成绩提交执行教师提交、学院/教务审批或退回、教务发布的状态流程，退回原因和状态通知可追踪。
- 学院查看本学院开课运行、教师工作量和质量聚合；小于 5 个成绩样本时隐藏质量数值。
- 新增响应式“教学运行”页面，三个角色显示不同标题、数据和操作。
- 教务和学院智能问数从原始教学明细收敛到专用汇总表，学院汇总仍强制学院行级范围。

## 权限边界

- 教师只能提交本人授课班成绩，不能审批。
- 学院只能查看和处理本学院异常、成绩和聚合。
- 教务负责全校异常刷新和已审批成绩发布，不默认读取作业正文。
- 成绩退回必须填写原因，教学异常解决必须填写处理说明。
- 学院质量聚合采用最小样本保护。
