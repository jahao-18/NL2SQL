# MVP 状态机与权限表

本文件定义阶段 1 至阶段 3 必须遵守的状态迁移、权限边界和隐私分级。服务层必须校验状态迁移，前端只负责展示可执行操作。

## 1. 命名约定

- 首版页面使用“学习支持待办”或“需关注事项”，不使用不可解释的“风险分”作为主展示。
- “正式学业警告”仅由教务规则和人工确认产生，首版不自动生成正式处分或警告结论。
- 作业状态、提交状态、支持事项状态均以英文枚举存储，以中文标签展示。

## 2. 作业状态机

| 状态 | 中文标签 | 说明 | 可见角色 |
| --- | --- | --- | --- |
| `draft` | 草稿 | 教师创建但未发布，学生不可见 | 任课教师 |
| `published` | 已发布 | 学生可见并可提交 | 任课教师、选课学生 |
| `closed` | 已截止 | 默认不可提交；若允许补交则可生成迟交提交 | 任课教师、选课学生 |
| `archived` | 已归档 | 仅保留查询和审计，不再操作 | 任课教师、选课学生、授权管理角色 |

### 2.1 作业状态迁移

| 当前状态 | 目标状态 | 触发动作 | 执行角色 | 校验 |
| --- | --- | --- | --- | --- |
| 无 | `draft` | 创建作业 | 任课教师 | 必须是该开课班任课教师 |
| `draft` | `published` | 发布作业 | 任课教师 | 标题、截止时间、满分、提交策略完整 |
| `published` | `closed` | 截止时间到达或教师手动截止 | 系统、任课教师 | 手动截止需写审计 |
| `closed` | `published` | 重新开放 | 任课教师 | 必须填写原因和新的截止时间 |
| `closed` | `archived` | 归档 | 任课教师 | 已完成批阅或确认不再批阅 |
| `draft` | `archived` | 删除/归档草稿 | 任课教师 | 学生不可见状态才允许直接归档 |

禁止迁移：

- `published -> draft`：已发布作业不能回到草稿，只能更正信息并留审计。
- `archived -> published`：归档作业不能重新开放，应创建新作业。
- 非任课教师修改任何作业状态。

## 3. 提交状态机

| 状态 | 中文标签 | 说明 | 学生可见 | 教师可见 |
| --- | --- | --- | --- | --- |
| `not_submitted` | 未提交 | 学生尚未提交 | 是 | 是 |
| `submitted` | 已提交 | 截止前提交，等待批阅 | 是 | 是 |
| `late_submitted` | 迟交 | 截止后按补交策略提交 | 是 | 是 |
| `returned` | 已退回 | 教师要求重交 | 是 | 是 |
| `resubmitted` | 已重交 | 退回后再次提交 | 是 | 是 |
| `graded_unpublished` | 已评分未发布 | 教师已评分，学生暂不可见分数 | 只见“批阅中” | 是 |
| `graded_published` | 成绩已发布 | 学生可见分数和评语 | 是 | 是 |

### 3.1 提交状态迁移

| 当前状态 | 目标状态 | 触发动作 | 执行角色 | 校验 |
| --- | --- | --- | --- | --- |
| `not_submitted` | `submitted` | 首次提交 | 学生本人 | 作业已发布且未截止 |
| `not_submitted` | `late_submitted` | 截止后补交 | 学生本人 | 作业已截止且允许补交 |
| `submitted` | `submitted` | 覆盖提交或新版本 | 学生本人 | 未截止；保留版本历史 |
| `submitted` | `returned` | 退回重交 | 任课教师 | 必须填写退回原因 |
| `late_submitted` | `returned` | 退回重交 | 任课教师 | 必须填写退回原因 |
| `returned` | `resubmitted` | 学生重交 | 学生本人 | 退回状态且仍允许重交 |
| `submitted` | `graded_unpublished` | 评分 | 任课教师 | 分数在 0 到满分之间 |
| `late_submitted` | `graded_unpublished` | 评分 | 任课教师 | 分数在 0 到满分之间 |
| `resubmitted` | `graded_unpublished` | 评分 | 任课教师 | 分数在 0 到满分之间 |
| `graded_unpublished` | `graded_published` | 发布成绩 | 任课教师 | 发布批次写入审计 |
| `graded_published` | `graded_unpublished` | 撤回发布 | 任课教师 | 必须填写撤回原因 |

禁止迁移：

- 学生直接修改 `graded_unpublished`、`graded_published`。
- 教师为非本人课程的提交评分。
- 学生替他人提交。
- 已归档作业下新增提交。

## 4. 学习支持待办状态机

| 状态 | 中文标签 | 说明 |
| --- | --- | --- |
| `open` | 待确认 | 规则命中后生成，尚未联系学生 |
| `contacted` | 已联系 | 辅导员已完成首次联系 |
| `tracking` | 跟进中 | 已制定后续计划或等待复查 |
| `improved` | 已改善 | 后续提交、出勤或成绩事实改善 |
| `closed` | 已关闭 | 事项处理结束，必须保留原因 |

### 4.1 支持待办状态迁移

| 当前状态 | 目标状态 | 触发动作 | 执行角色 | 校验 |
| --- | --- | --- | --- | --- |
| 无 | `open` | 规则命中 | 系统 | 必须有事实依据和责任辅导员 |
| `open` | `contacted` | 记录首次联系 | 辅导员 | 必须填写联系方式和摘要 |
| `contacted` | `tracking` | 制定跟进计划 | 辅导员 | 必须填写复查日期 |
| `tracking` | `improved` | 复查发现改善 | 辅导员、系统辅助 | 必须引用后续事实 |
| `open` | `closed` | 确认为误触发或无需跟进 | 辅导员 | 必须填写关闭原因 |
| `contacted` | `closed` | 完成处理 | 辅导员 | 必须填写关闭原因 |
| `tracking` | `closed` | 完成处理 | 辅导员 | 必须填写关闭原因 |
| `improved` | `closed` | 归档事项 | 辅导员 | 必须填写总结 |

禁止迁移：

- 教师关闭或查看辅导员工作记录。
- 学生关闭学习支持待办。
- 系统自动删除历史事项。
- 只凭不可解释模型分数创建事项。

## 5. 首版触发规则

| 规则编码 | 触发条件 | 生成事项标题 | 事实依据 |
| --- | --- | --- | --- |
| `two_missing_assignments_same_course` | 同一课程连续两次作业未提交 | 连续未提交课程作业 | 课程、作业名称、截止时间、未提交状态 |
| `two_late_submissions_same_course` | 同一课程累计两次迟交 | 多次迟交课程作业 | 课程、作业名称、提交时间、截止时间 |
| `two_absences_same_course` | 同一课程连续两次缺勤 | 连续缺勤需确认 | 课程、课次、考勤日期、缺勤状态 |

规则只创建“待确认事项”，不直接生成正式学业警告。

## 7. 数据隐私分级

| 等级 | 数据类型 | 示例 | 可访问角色 | 保留与展示规则 |
| --- | --- | --- | --- | --- |
| P0 公开教学配置 | 课程名称、作业标题、截止时间 | 数据库系统第 3 次作业 | 课程成员 | 按课程成员关系展示 |
| P1 个人学习过程 | 本人提交状态、提交时间、成绩 | 学生自己的作业和分数 | 学生本人、任课教师 | 学生只看本人；教师只看本课 |
| P2 班级教学事实 | 未交人数、迟交率、待批数 | 本班作业完成率 | 任课教师、授权管理角色 | 默认聚合展示 |
| P3 学生支持事项 | 连续未交触发依据、联系记录 | 学习支持待办 | 对应学生的辅导员；学生只看建议 | 教师不可见内部记录 |
| P4 敏感正文/附件 | 作业附件正文、辅导员谈话细节 | 上传文件、跟进摘要 | 严格按业务需要授权 | 日志不记录正文；下载二次鉴权 |

## 8. API 设计约束

- 所有业务 API 从登录上下文推导 `student_id`、`teacher_id`、`counselor_id`，不得信任前端传入的身份范围。
- 对越权资源统一返回 `403`，响应中不说明目标对象是否存在。
- 文件下载、提交详情、成绩发布、跟进记录必须二次校验权限。
- 所有写操作记录审计：操作者、角色、资源类型、资源 ID、动作、前状态、后状态、时间。
- NL2SQL 只能读取授权后的分析视图，不能直接读取 P3、P4 数据。

## 9. 阶段 0 完成定义

- 作业、提交、学习支持待办不存在未定义状态。
- 每个状态迁移都有执行角色和服务端校验点。
- 权限矩阵覆盖学生、教师、辅导员三类首版角色。
- 隐私分级明确说明教师不查看学业支持内部记录。
