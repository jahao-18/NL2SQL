# V3-2.1 认证指标语义层实施结果

> 完成日期：2026-07-19
> 状态：后端与 API 已完成，前端接入仍属于 V3-3

## 1. 交付结果

V3-2.1 已建立受版本控制的认证指标字典，并让固定指标接口和统一助手自然语言问法共用同一个指标匹配、权限复核与计算服务。指标结果不会依赖模型临时生成 SQL，因此页面卡片与智能问数可以得到一致的值、样本量、口径和警告。

主要文件：

- `data/semantic_metrics.yaml`：21 个首批指标的版本化定义。
- `app/core/semantic_metrics.py`：指标加载、可见性筛选、别名匹配、范围化计算和统一响应。
- `app/api/assistant.py`：`GET /api/assistant/metrics` 固定指标接口。
- `app/core/assistant_orchestrator.py`：认证指标优先路由。
- `tests/test_semantic_metrics.py`：口径一致性、权限和不可用状态回归。

## 2. 首批指标

| 业务域 | 指标 | 当前状态 |
|---|---|---|
| 作业 | 完成率、迟交率、未交数、待批数 | 已实现，按学生本人或教师本人授课班计算 |
| 考勤 | 出勤率、缺勤次数、连续缺勤 | 已实现，按本人、授课班或辅导员带班范围计算 |
| 成绩 | 提交状态、发布进度、成绩分布、通过率 | 已实现，按教师、学院、教务或学生本人范围计算 |
| 教学运行 | 开放异常、逾期异常、平均处理时长 | 已实现，学院负责人限本学院，教务按授权范围 |
| 学生支持 | 待联系、待复查、逾期复查 | 已实现，仅辅导员本人负责个案 |
| 平台运维 | 问数成功率、降级率 | 已实现，仅管理员 |
| 平台运维 | 低置信率、阶段耗时 | 已在 V3-2.2 接入脱敏统一执行轨迹 |

每项定义均包含公式、业务来源、时间语义、适用角色、页面、内部行范围、最小样本量、下钻能力和单位。对外响应不暴露角色清单、内部行范围、物理表或 SQL 模板。

## 3. 接口与智能问法

固定接口示例：

```http
GET /api/assistant/metrics?page=course_analytics&teaching_class_id=900001&code=assignment_completion_rate
X-Demo-Token: <current-session-token>
```

统一助手在问题命中认证指标名称或别名时，先执行服务端页面上下文校验，再调用同一指标求值器。响应中的 `data.metric` 与固定接口的指标对象一致，并提供：

- 指标定义与口径；
- 值、单位和样本量；
- 小样本标记与结构化警告；
- 业务分项及数据更新时间；
- `semantic_metric` 安全执行摘要。

未命中认证指标的问题继续按 V3-1.3 路由到业务状态、导航、NL2SQL 或不支持分支。已有 `/api/ask` 保持兼容。

## 4. 权限与现实边界

- 请求上下文只能收窄当前工作身份范围；伪造其他教师课程等请求在计算前返回 403。
- 指标目录按当前角色和页面过滤；不可见指标与未知指标统一返回 404，避免通过目录探测内部能力。
- 百分比在分母为零时返回 `null`，不返回伪造的 0%；低于最小样本量时保留事实值并附谨慎解读警告。
- 指标字典版本已在 V3-2.2 升级为 2；低置信率和阶段耗时现从脱敏执行轨迹计算，不读取问题正文、SQL 或结果行。
- 本阶段没有新增前端指标卡或助手组件；网页仍未消费此 API。
- 当前指标是状态快照或现有保留期统计，跨周、跨月和跨学期趋势仍需后续历史快照能力。

## 5. 验证结果

- 新增认证指标专项用例 5 项。
- 固定 API 与自然语言问法返回完全相同的指标对象。
- 覆盖安全字段输出、角色/页面可见性、教师课程越权、条件不可用及未知指标。
- 对管理员、教务、学院、教师、辅导员、学生六类身份完成接口冒烟检查。
- 全量自动化结果：`202 passed, 2 warnings`。两条 warning 为既有 Starlette TestClient/httpx 和 `langchain-community` 弃用提示。
