# 阶段 F 实施记录

## 已实现

- 建立学生、教师、辅导员、学院负责人、教务人员、管理员六角色菜单与关键接口允许/拒绝矩阵。
- 集中检查会话响应不泄露内部表白名单、行范围和敏感字段策略。
- pytest 全局夹具将教学数据库、课程资料和作业附件隔离到临时目录，阶段 F 新增显式断言防止回归到共享库。
- 新增 `scripts/run_stage_f_regression.py`，可一键执行阶段 F 权限矩阵和公告、作业、考勤、答疑、辅导员跟进、教学异常与成绩审批演示链路。
- 学生正式获得独立首页导航入口，与已有学生范围化工作台数据对齐。
- 通知响应新增安全业务页面目标；通知中心支持未读数、加载/空/错误态、标记已读和业务页面跳转。
- 前端静态回归覆盖空态、错误态、未登录态、关键移动端断点和通知跳转契约。
- 新增六角色手工演示顺序、预期权限边界和成绩状态联动说明。

## 验收边界

- 自动化回归验证接口和响应式代码契约，不替代生产环境真机、多浏览器、性能和无障碍验收。
- 手工演示会写入当前演示库；稳定重复演示应使用临时数据库的一键回归脚本。
