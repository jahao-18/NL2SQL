# B.7-1 账号安全冻结与恢复实施说明

完成日期：2026-07-17

## 已交付

- 平台管理员可对已核验人员账号执行安全冻结与恢复。
- 冻结、恢复均需要操作依据和当前管理员密码二次验证。
- 每次状态迁移递增账号 `session_version`，立即撤销所有旧会话；冻结状态拒绝登录、令牌校验和新令牌签发。
- 正式平台管理员不能冻结自身；冻结后正式平台管理员少于两人时会被阻止。
- 冻结不撤销岗位或身份，恢复也绝不反向恢复冻结期间已经撤销、结束或到期的绑定。
- 全过程记录生命周期事件、账号状态历史和安全审计；组织教职工目录提供管理员入口。

## 接口

- `POST /api/lifecycle/people/{person_identity_id}/security-suspend`
- `POST /api/lifecycle/people/{person_identity_id}/security-restore`

请求体均为：`{"reason":"操作依据","reauth_password":"当前管理员密码"}`。

## 自动化验证

专项测试覆盖冻结后旧令牌/登录/签发令牌失效、错误二验不改状态、非管理员拒绝、正式管理员保底，以及恢复不复活已撤销教师绑定。
