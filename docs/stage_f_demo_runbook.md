# 阶段 F 产品回归与演示手册

## 1. 稳定回归入口

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts\run_stage_f_regression.py --verbose
```

脚本会在系统临时目录中建立 pytest 运行空间；测试夹具复制教学库后再执行所有写操作，不会修改 `data/teaching.db`、课程资料目录或作业附件目录。

需要运行全量测试时使用：

```powershell
.\.venv\Scripts\python.exe scripts\run_stage_f_regression.py --full
```

## 2. 演示前准备

1. 启动后端：`uvicorn app.main:app --reload`。
2. 浏览器使用 `Ctrl+F5` 刷新静态资源。
3. 六类主演示账号分别为 `stu_zhang`、`tea_li`、`counselor_chen`、`college`、`jwc`、`admin`。登录凭据只查看本地忽略文件 `docs/demo_accounts_private.md`，不要复制到公开文档或演示截图。
4. 手工演示会写入当前演示库。需要完全可重复且不污染演示库时，优先运行上一节的一键脚本。

## 3. 六角色演示顺序

### 3.1 教师：发布内容与课堂点名

1. 使用 `tea_li` 登录，首先展示“教学首页”只包含本人授课班。
2. 进入“我的课程”，选择本人课程并发布一条公告；可同时上传一个受控格式的小附件。
3. 进入“课程考勤”，建立课程场次并登记学生出勤；再次保存一名学生的修正状态，展示修正审计能力。
4. 进入“课程答疑”，确认教师端只有回复、关闭和置顶操作，没有“向教师提问”表单。

预期：教师无法操作其他教师的课程，公告只送达本课程学生。

### 3.2 学生：通知跳转、提交与提问

1. 使用 `stu_zhang` 登录，展示独立“我的首页”和本人课程待办。
2. 进入“通知中心”，确认未读数和教师刚发布的公告，点击“查看详情”跳转到“我的课程”。
3. 在“课程作业”中提交本人作业；在“课程答疑”中创建公开或私密问题。
4. 查看“课程考勤”，确认只能看到本人考勤记录。

预期：学生不能读取同学提交、他人考勤、跨课程内容或私密问题。

### 3.3 辅导员：学习支持跟进

1. 使用 `counselor_chen` 登录，展示本人所带班级、待跟进个案和学生预约。
2. 进入“学习支持”，对开放个案依次记录联系、复查时间、改善情况和关闭原因。
3. 选择“同步更新学生端支持建议”后，再用对应学生账号确认只看到公开建议，不看到内部日志。

预期：辅导员不能访问非带班学生，教师不能查看辅导员跟进记录。

### 3.4 教务：处理确定性异常

1. 使用 `jwc` 登录，进入“教学运行”。
2. 点击刷新确定性异常，查看缺少教室、容量异常或低选课量事项。
3. 将一条事项更新为“处理中”，再填写处理说明并解决。

预期：教务看到全校教学管理范围，但不能读取原始评教文本或普通课程成员隐私。

### 3.5 学院：范围化审批与聚合

1. 使用 `college` 登录，展示本学院教学运行、教师工作量和质量聚合。
2. 在成绩提交区按学年、学院、学期和状态筛选待审批记录。
3. 对教师提交的成绩执行通过或退回；退回时必须填写原因。

预期：学院下拉项和数据只包含本学院，不能通过参数访问其他学院。

### 3.6 管理员：平台运维与权限隔离

1. 使用 `admin` 登录，展示数据源健康、审计活动、知识库和治理入口。
2. 查看数据接入与治理队列，确认页面不显示普通账号密码或账号花名册。
3. 尝试打开教学运行业务接口应被拒绝；管理员不替代教务、学院或辅导员执行业务决定。

## 4. 成绩状态联动演示

1. 教师在“教学运行”提交课程成绩状态。
2. 学院负责人将状态审批为“已审批”，或退回教师修改。
3. 教务人员发布已审批成绩。
4. 教师在通知中心收到状态更新，并可跳回教学运行页面。

状态必须按 `未提交 → 待审批 → 已审批/已退回 → 已发布` 流转，越级操作由后端拒绝。

## 5. 页面状态验收清单

- 空列表显示说明性空态，不保留无内容的大块空框。
- 请求失败显示页面内错误态，不把接口异常当成空数据。
- 未登录接口返回 `401`，角色越权接口返回 `403`。
- 服务端导航不下发无权限页面；直接调用接口仍由后端再次校验。
- 通知“查看详情”先标记本人通知已读，再跳转到对应业务页面。
- 桌面、平板、手机断点下不出现固定宽度挤压；长列表使用内部滚动或单列布局。

当前自动化覆盖响应式结构和关键断点，但不等同于生产环境多浏览器、无障碍与真机兼容验收。
