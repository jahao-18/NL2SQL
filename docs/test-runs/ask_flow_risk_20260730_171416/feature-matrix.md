# 问数流程功能矩阵

| ID | 优先级 | 可观察功能 | 主要入口 | 预期 |
|---|---|---|---|---|
| F-001 | P1 | 共享问数面板加载与统一请求 | `assistant-panel.js`、`POST /api/assistant/query` | 页面组件与 API 契约一致 |
| F-002 | P1 | 问题分类 | 统一助手编排器 | 导航、指标、状态、NL2SQL、不支持问题分别进入正确分支 |
| F-003 | P1 | NL2SQL 主链 | Schema→检索→生成→校验→执行→格式化 | 返回受限 SQL、数据、证据和结构化状态 |
| F-004 | P0 | 权限与安全 | 身份、上下文、表/列/行范围校验 | 跨身份、跨课程、敏感字段和绕过语句被拒绝 |
| F-005 | P1 | 会话与追问 | 助手会话和服务端历史 | 追问使用本人有效历史，客户端伪造历史不覆盖 |
| F-006 | P1 | 失败降级 | 模型、检索、总超时 | 返回结构化失败，普通业务 API 可继续使用 |
| F-007 | P2 | 旧接口兼容 | `POST /api/ask` | 旧入口仍保持原响应契约 |
| F-008 | P1 | 新总评数据关联 | 学生首页与学生问数 | 教务已发布总评在两个入口口径一致，未发布不泄露 |
