# V3-2.2 回答证据与执行链路摘要实施结果

> 完成日期：2026-07-19
> 状态：后端与统一助手 API 已完成，前端证据卡片仍属于 V3-3

## 1. 交付结果

统一助手现在会在返回答案的同时给出最终页面与数据范围、时间范围、业务来源、指标口径、数据更新时间或查询时间、结构化质量提示和安全执行阶段摘要。用户不必阅读 SQL，也能判断回答统计了什么、来自哪里、是否被截断或降级。

主要文件：

- `app/core/answer_evidence.py`：范围摘要、证据补全、质量提示、公开/管理员轨迹和脱敏持久化。
- `app/core/v3_migrations.py`：V3 schema 3003 新增 `query_execution_trace`。
- `app/core/assistant_orchestrator.py`：统一证据编排、公开轨迹和回答后轨迹落库。
- `app/service.py`：记录检索、模型、SQL 校验和执行阶段耗时及降级状态。
- `tests/test_answer_evidence.py`：普通用户/管理员可见性、隐私、降级和轨迹指标回归。

## 2. 用户可见回答证据

统一查询响应现在稳定提供：

- `scope`：当前角色、角色名称、页面、显式课程/学生/学院、学年、学期和安全筛选键摘要。
- `time_range`：页面传入的带时区起止时间及口径说明。
- `evidence`：业务来源、指标编码、时间语义、数据更新时间或查询时间。
- `metric_definitions`：认证指标名称、公式、来源、时间口径、样本规则和下钻能力。
- `warnings`：包含 `code / severity / message` 的结构化提示。
- `trace_summary`：路由、阶段成功/失败/跳过、是否降级、失败阶段和总耗时。

当前结构化提示覆盖：

| 代码 | 场景 |
|---|---|
| `SMALL_SAMPLE` | 认证指标低于建议最小样本量 |
| `EMPTY_RESULT` | 当前范围没有可返回数据 |
| `TRUNCATED` | 服务端上限或本次 `max_rows` 导致截断 |
| `LOW_CONFIDENCE` | 置信度低于治理设置阈值 |
| `RETRIEVAL_DEGRADED` | Schema 检索异常并使用安全回退路径 |
| `CONTEXT_IGNORED` | 页面无关上下文字段被服务端忽略 |

检索降级但查询成功时，回答状态为 `degraded`，而不是伪装成完全成功或直接终止基础业务。

## 3. 普通用户与管理员边界

普通用户即使请求 `include_trace=true`，也只能看到各阶段的安全状态，不返回阶段精确耗时、检索器清单、候选表、Schema 片段、Prompt 或内部异常。

平台管理员只有在显式设置 `include_trace=true` 时，才额外看到：

- 检索是否使用或降级；
- 实际参与的检索器名称；
- 上下文、路由、检索、模型、校验和执行阶段耗时；
- 安全回修尝试次数和降级原因。

管理员响应仍不会包含 `context_preview`、完整 Prompt、连接地址、密钥或原始堆栈。

## 4. 脱敏执行轨迹

`query_execution_trace` 与助手轮次一对一关联，仅保存：

- 路由与检索状态；
- 检索器名称数组；
- 阶段状态与毫秒耗时；
- 降级与失败阶段；
- 总耗时、置信度、结果行数和截断状态。

该表没有问题正文、回答正文、完整上下文、SQL、结果行、作业正文、附件或辅导记录字段。轨迹写入失败只记录服务端异常，不破坏已经完成的只读回答。

## 5. 对认证指标的影响

V3-2.1 中等待统一轨迹的两个管理员指标现已可用：

- `assistant_low_confidence_rate`：按当前治理阈值统计有置信度轨迹中的低置信轮次比例。
- `assistant_stage_latency`：按持久化阶段轨迹计算各阶段平均耗时及样本量。

指标 YAML 版本由 1 更新为 2。问数成功率和降级率继续以助手轮次状态为事实来源。

## 6. 当前边界

- 当前网页尚未渲染证据卡片、结构化提示和阶段摘要，仍属于仅后端能力。
- 异步裁判尚未把后续生成的置信度回写到既有执行轨迹；只有查询响应当时已有的置信度参与低置信指标。
- 阶段耗时是应用编排阶段统计，不是分布式链路追踪；没有跨进程 trace/span 或外部监控告警。
- NL2SQL 通用数据源只能提供本次查询时间，无法统一推断各业务表的真实最后更新时间；认证指标会提供其可取得的数据更新时间。
- 质量运营筛选和管理页面属于后续管理员运营阶段，不在本任务内。
